# Local UI and HTML Brief Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `rentsmart --html PATH` (one self-contained, shareable brief page) and `rentsmart-ui` (a localhost app for asking-price what-ifs and running new addresses), both rendering the existing `Brief` with the same templates.

**Architecture:** A new `rentsmart.web` package is a third view on `core/engine.py::build_brief`, beside `render.py` (text) and `--json`. `web/view.py` turns a `Brief` into display data (pure functions, no advice), `web/render.py` fills Jinja templates, `web/app.py` is a FastAPI app bound to 127.0.0.1. The RentCast provider gains an `offline` mode (cache only, raises `CacheMiss`) and a per-month `UsageLog`, so only `POST /brief` can spend API calls.

**Tech Stack:** Python 3.12, uv, FastAPI, uvicorn, Jinja2, Typer, Pydantic 2, httpx/respx, pytest, ruff, pyright (strict on `src/`). No Node, no build step, no CDN.

**Spec:** `docs/superpowers/specs/2026-10-26-local-ui-design.md`

## Global Constraints

- Tests never call the live RentCast API; `tests/conftest.py::no_live_http` stays autouse.
- The API key comes only from `RENTCAST_API_KEY`; never in a template, response, log, or URL.
- `core/` does not change. The UI adds no advice: suggestions and questions come only from `core/rules.py`; check chips restate brief values with the existing `RECENT_GAP` constant.
- Only `POST /brief` may make live API calls. `GET /brief` and `GET /brief/sections` are cache-only.
- The app binds `127.0.0.1` only; requests with any other `Host` get 400; `POST` with a foreign `Origin`/`Referer` gets 403.
- `--html` output has no external URLs: no `<script src`, no stylesheet `<link>`, no `http(s)://` asset references.
- `rentsmart "<address>"` stays a single command; the app is a separate script `rentsmart-ui`.
- Default port 8765; `--no-open` disables opening the browser.
- Slider: 15% below the estimate low to 15% above the high, $25 steps, 250 ms debounce.
- Conventional commits (`feat:`, `refactor:`, `docs:`, `test:`), each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never hand-edit the version or `CHANGELOG.md`.
- Each task ends green: `uv run pytest -q`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run pyright`, `uv run rentsmart-eval --check`.

## Review Focus

1. **Bad asking input** (`nan`, `inf`, `-5`, `abc`, `1e9`) in the app: a 422 page with a plain message, never a 500 or a brief built from it. Test in Task 6.
2. **`RENTSMART_CACHE_DAYS=0`** in the app: the GET → Run → redirect → GET loop would never find a cache. Expected: a config message saying the UI needs the cache. Test in Task 6.
3. **HTML in addresses** (typed by the user or returned by the vendor, including ambiguous candidates): escaped everywhere, including candidate links. Tests in Task 4 and Task 6.
4. **`--html` to an unwritable path:** a one-line message and exit 1, no traceback, no half-written file. Test in Task 5.
5. **A brief with no range** (too few comps, no rent estimate): page and what-if render with the banner, no price line, no slider, no crash. Tests in Task 3 and Task 4.

```python
"""Settings read from the environment, shared by the CLI and the local UI."""

import os
from datetime import timedelta

from rentsmart.contracts import ConfigError
from rentsmart.core.freshness import DEFAULT_STALE_AFTER_DAYS
from rentsmart.providers.cache import (
    CACHE_DAYS_ENV,
    DEFAULT_MAX_AGE_DAYS,
    ResponseCache,
    default_cache_dir,
)

STALE_ENV = "RENTSMART_STALE_AFTER_DAYS"


def _whole_days(env: str, default: int) -> int:
    raw = os.environ.get(env, "").strip()
    if not raw:
        return default
    if not raw.isdigit():
        raise ConfigError(f"{env} must be a whole number of days, got {raw!r}.")
    return int(raw)


def stale_after_days() -> int:
    return _whole_days(STALE_ENV, DEFAULT_STALE_AFTER_DAYS)


def response_cache(refresh: bool = False) -> ResponseCache | None:
    """The local response cache, or None when RENTSMART_CACHE_DAYS is 0."""
    days = _whole_days(CACHE_DAYS_ENV, DEFAULT_MAX_AGE_DAYS)
    if days == 0:
        return None
    return ResponseCache(default_cache_dir(), timedelta(days=days), read=not refresh)
```

```python
USAGE_FILE = "usage.json"


class CacheMiss(Exception):
    """A response isn't cached and the provider is offline. Nothing was fetched.

    Not a RentsmartError: it has no exit code and only the web UI catches it.
    """

    def __init__(self, path: str) -> None:
        super().__init__(f"{path} is not cached")
        self.path = path


class UsageLog:
    """Live API responses per month on this machine. A guide, not the vendor's count."""

    def __init__(self, root: Path, today: Callable[[], date] = date.today) -> None:
        self._file = root / USAGE_FILE
        self._today = today

    def _month(self) -> str:
        return f"{self._today():%Y-%m}"

    def _read(self) -> dict[str, int]:
        try:
            data = json.loads(self._file.read_text())
        except (OSError, ValueError):
            return {}
        if not isinstance(data, dict):
            return {}
        counts = cast(dict[str, object], data)
        return {k: v for k, v in counts.items() if isinstance(v, int)}

    def this_month(self) -> int:
        return self._read().get(self._month(), 0)

    def record(self) -> None:
        counts = self._read()
        month = self._month()
        counts[month] = counts.get(month, 0) + 1
        try:
            self._file.parent.mkdir(parents=True, exist_ok=True)
            self._file.write_text(json.dumps(counts))
        except OSError:
            pass  # counting must never break a brief
```

```python
"""Display data for the HTML brief. Restates values already in the brief; adds no advice."""

import math
import re
from dataclasses import dataclass
from typing import Any

from rentsmart.contracts import Brief, Comp, Envelope
from rentsmart.core.rules import RECENT_GAP

SLIDER_SPAN = 0.15
SLIDER_STEP = 25
LABEL_MIN, LABEL_MAX = 18.0, 82.0  # keep centred labels inside the line on phones
_HISTORY = re.compile(r"^(\d{4}-\d{2}): median (\d+(?:\.\d+)?)$")
_OUTSIDE = ("above range", "below range")


def money(amount: float) -> str:
    return f"${amount:,.0f}"


@dataclass(frozen=True)
class Chip:
    label: str
    detail: str
    warn: bool


def checks(brief: Brief) -> list[Chip]:
    lst = brief.listing
    if lst is None:
        return []
    chips: list[Chip] = []
    if lst.range_position is not None:
        pos = lst.range_position.value
        outside = pos in _OUTSIDE
        chips.append(Chip("Outside range" if outside else "In range", pos, outside))
    if lst.vs_recent_comps is not None and brief.recent_comps is not None:
        gap = lst.vs_recent_comps.value
        chips.append(
            Chip(
                f"{gap * 100:+.1f}% vs recent comps",
                f"median {money(brief.recent_comps.value)}",
                abs(gap) >= RECENT_GAP,
            )
        )
    median = brief.market.median_days_on_market
    if lst.days_listed is not None and median is not None:
        days = lst.days_listed.value
        chips.append(
            Chip(f"{days} days listed", f"zip median {median.value:.0f}", days > median.value)
        )
    return chips


@dataclass(frozen=True)
class Mark:
    kind: str  # comp, comp-active, comp-old, mid, asking, recent
    pct: float
    row: int
    title: str


@dataclass(frozen=True)
class Label:
    kind: str  # asking, mid, low, high, recent
    pct: float
    text: str


@dataclass(frozen=True)
class PriceLine:
    low_pct: float
    high_pct: float
    marks: list[Mark]
    labels: list[Label]


def _asking(brief: Brief) -> float | None:
    return brief.listing.asking_rent.value if brief.listing else None


def price_line(brief: Brief) -> PriceLine | None:
    est = brief.rent_estimate
    if est is None or est.low is None or est.high is None:
        return None
    asking = _asking(brief)
    recent = brief.recent_comps.value if brief.recent_comps else None
    prices = [c.value.price for c in brief.comps] + [est.low, est.high]
    prices += [p for p in (asking, recent) if p is not None]
    lo, hi = min(prices), max(prices)
    pad = (hi - lo) * 0.05 or 50.0
    lo, hi = lo - pad, hi + pad

    def pct(price: float) -> float:
        return round((price - lo) / (hi - lo) * 100, 2)

    def label_pct(price: float) -> float:
        return min(max(pct(price), LABEL_MIN), LABEL_MAX)

    marks: list[Mark] = []
    stacked: dict[float, int] = {}
    for env in brief.comps:
        comp = env.value
        row = stacked.get(comp.price, 0)
        stacked[comp.price] = row + 1
        kind = "comp-old" if env.stale else ("comp-active" if comp.status == "active" else "comp")
        title = f"{comp.address}: {money(comp.price)} ({comp.status})"
        marks.append(Mark(kind, pct(comp.price), row, title))
    marks.append(Mark("mid", pct(est.value), 0, f"Estimate mid {money(est.value)}"))
    labels = [
        Label("low", label_pct(est.low), money(est.low)),
        Label("high", label_pct(est.high), money(est.high)),
        Label("mid", label_pct(est.value), f"mid {money(est.value)}"),
    ]
    if recent is not None:
        marks.append(Mark("recent", pct(recent), 0, f"Recent comp median {money(recent)}"))
        labels.append(Label("recent", label_pct(recent), f"recent median {money(recent)}"))
    if asking is not None:
        marks.append(Mark("asking", pct(asking), 0, f"Your asking {money(asking)}"))
        labels.append(Label("asking", label_pct(asking), f"your asking {money(asking)}"))
    return PriceLine(pct(est.low), pct(est.high), marks, labels)


@dataclass(frozen=True)
class Slider:
    min: int
    max: int
    step: int
    mid: int


def slider(brief: Brief) -> Slider | None:
    est = brief.rent_estimate
    if est is None or est.low is None or est.high is None:
        return None
    low = math.floor(est.low * (1 - SLIDER_SPAN) / SLIDER_STEP) * SLIDER_STEP
    high = math.ceil(est.high * (1 + SLIDER_SPAN) / SLIDER_STEP) * SLIDER_STEP
    asking = _asking(brief)
    if asking is not None:
        low = min(low, math.floor(asking / SLIDER_STEP) * SLIDER_STEP)
        high = max(high, math.ceil(asking / SLIDER_STEP) * SLIDER_STEP)
    mid = round(est.value / SLIDER_STEP) * SLIDER_STEP
    return Slider(low, high, SLIDER_STEP, mid)


def market_history(brief: Brief) -> list[tuple[str, float]]:
    """Monthly medians, read back from the trend's evidence lines ("2026-05: median 28")."""
    trend = brief.market.trend
    if trend is None:
        return []
    points: list[tuple[str, float]] = []
    for line in trend.evidence:
        if match := _HISTORY.match(line):
            points.append((match.group(1), float(match.group(2))))
    return points


@dataclass(frozen=True)
class Spark:
    points: str  # SVG polyline points in a 260x60 box
    first: str
    last: str
    last_value: float


def sparkline(history: list[tuple[str, float]]) -> Spark | None:
    if len(history) < 2:
        return None
    width, height, pad = 260, 60, 6
    top = max(v for _, v in history) * 1.15 or 1.0
    step = (width - 2 * pad) / (len(history) - 1)
    coords = [
        f"{pad + i * step:.1f},{height - pad - v / top * (height - 2 * pad):.1f}"
        for i, (_, v) in enumerate(history)
    ]
    return Spark(" ".join(coords), history[0][0], history[-1][0], history[-1][1])


@dataclass(frozen=True)
class CompRow:
    comp: Comp
    stale: bool
    divider_before: bool


def comp_rows(brief: Brief) -> list[CompRow]:
    rows: list[CompRow] = []
    divided = False
    for env in brief.comps:
        divider = env.stale and not divided
        divided = divided or env.stale
        rows.append(CompRow(env.value, env.stale, divider))
    return rows


def _num(value: float) -> str:
    return f"{value:g}"


def fact_line(brief: Brief) -> str:
    f = brief.facts
    parts: list[str] = []
    if f.property_type:
        parts.append(f.property_type.value)
    if f.beds:
        parts.append(f"{_num(f.beds.value)} bd")
    if f.baths:
        parts.append(f"{_num(f.baths.value)} ba")
    if f.sqft:
        parts.append(f"{f.sqft.value:,} sqft")
    if f.year_built:
        parts.append(f"built {f.year_built.value}")
    return " · ".join(parts)


@dataclass(frozen=True)
class DetailRow:
    label: str
    value: str
    env: Envelope[Any]


def detail_rows(brief: Brief) -> list[DetailRow]:
    f, rows = brief.facts, list[DetailRow]()

    def add(label: str, env: Envelope[Any] | None, value: str | None = None) -> None:
        if env is not None:
            rows.append(DetailRow(label, value if value is not None else str(env.value), env))

    add("Address", f.address)
    add("Match confidence", f.match_confidence, f"{f.match_confidence.value:.0%}")
    add("Property type", f.property_type)
    add("Beds", f.beds, _num(f.beds.value) if f.beds else None)
    add("Baths", f.baths, _num(f.baths.value) if f.baths else None)
    add("Sqft", f.sqft, f"{f.sqft.value:,}" if f.sqft else None)
    add("Year built", f.year_built)
    add("Roof year", f.roof_year)
    add("HVAC year", f.hvac_year)
    est = brief.rent_estimate
    if est is not None:
        has_range = est.low is not None and est.high is not None
        span = f"{money(est.low or 0)}–{money(est.high or 0)}, " if has_range else ""
        add("Rent estimate", est, f"{span}mid {money(est.value)}")
    if brief.recent_comps:
        add("Recent comp median", brief.recent_comps, money(brief.recent_comps.value))
    if lst := brief.listing:
        add("Asking rent", lst.asking_rent, money(lst.asking_rent.value))
        add("Days listed", lst.days_listed)
        add("Range position", lst.range_position)
        gap = lst.vs_recent_comps
        add("vs recent comps", gap, f"{gap.value * 100:+.1f}%" if gap else None)
        days = lst.vs_zip_median_days
        add("vs zip median days", days, f"{days.value:+.0f} days" if days else None)
    median = brief.market.median_days_on_market
    add("Zip median days on market", median, f"{median.value:.0f}" if median else None)
    add("Market trend", brief.market.trend)
    tax = brief.property_tax
    add("Property tax", tax, f"{money(tax.value)} / year" if tax else None)
    return rows
```

```python
"""Brief -> HTML. One set of templates serves the shareable file and the local app."""

from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from datetime import date
from importlib.resources import files
from typing import Any

from jinja2 import Environment, PackageLoader, StrictUndefined, select_autoescape

from rentsmart.contracts import Brief, RentsmartError
from rentsmart.web import view

_env = Environment(
    loader=PackageLoader("rentsmart.web", "templates"),
    autoescape=select_autoescape(default=True, default_for_string=True),
    undefined=StrictUndefined,
    trim_blocks=True,
    lstrip_blocks=True,
)
_env.filters["money"] = view.money


def static_text(name: str) -> str:
    return files("rentsmart.web").joinpath("static", name).read_text(encoding="utf-8")


@dataclass(frozen=True)
class WhatIf:
    asking: float
    entered: float


def _layout(app: bool) -> dict[str, Any]:
    if app:
        return {"inline": False, "css": "", "js": ""}
    return {"inline": True, "css": static_text("app.css"), "js": static_text("app.js")}


def _live_context(brief: Brief, entered: float | None) -> dict[str, Any]:
    asking = brief.listing.asking_rent.value if brief.listing else None
    whatif = (
        WhatIf(asking, entered)
        if asking is not None and entered is not None and asking != entered
        else None
    )
    return {
        "brief": brief,
        "line": view.price_line(brief),
        "chips": view.checks(brief),
        "spark": view.sparkline(view.market_history(brief)),
        "comps": view.comp_rows(brief),
        "details": view.detail_rows(brief),
        "whatif": whatif,
    }


def render_page(
    brief: Brief,
    *,
    app: bool = False,
    entered: float | None = None,
    listed: date | None = None,
    today: date | None = None,
) -> str:
    asking = brief.listing.asking_rent.value if brief.listing else None
    return _env.get_template("brief.html").render(
        **_layout(app),
        **_live_context(brief, entered),
        app=app,
        street=brief.facts.address.value.split(",")[0],
        fact_line=view.fact_line(brief),
        slider=view.slider(brief),
        asking_value=f"{asking:g}" if asking is not None else "",
        entered=f"{entered:g}" if entered is not None else None,
        listed=listed.isoformat() if listed else "",
        today=(today or date.today()).isoformat(),
    )


def render_live(brief: Brief, *, entered: float | None = None) -> str:
    return _env.get_template("_live.html").render(**_live_context(brief, entered))


def render_index(
    *, usage: int, error: str | None = None, values: Mapping[str, str] | None = None
) -> str:
    return _env.get_template("index.html").render(
        **_layout(True), usage=usage, error=error, values=dict(values or {})
    )


def render_not_cached(query: Mapping[str, str], *, usage: int) -> str:
    return _env.get_template("not_cached.html").render(
        **_layout(True), query=dict(query), usage=usage
    )


def render_error(
    err: RentsmartError, *, address: str, links: Sequence[tuple[str, str]] = ()
) -> str:
    return _env.get_template("error.html").render(
        **_layout(True), err=err, address=address, links=list(links)
    )


def render_notice(message: str, *, link: str | None = None) -> str:
    return _env.get_template("notice.html").render(message=message, link=link)
```

```js
// rentsmart: tabs (progressive enhancement), print expansion, and the asking-price what-if.
(() => {
  let current = "panel-advice";

  const show = (wanted) => {
    const tabs = document.querySelectorAll('[role="tab"]');
    if (!tabs.length) return;
    const id = document.getElementById(wanted) ? wanted : tabs[0].dataset.panel;
    current = id;
    tabs.forEach((t) => {
      const on = t.dataset.panel === id;
      t.setAttribute("aria-selected", String(on));
      const panel = document.getElementById(t.dataset.panel);
      if (panel) panel.hidden = !on;
    });
  };

  // Delegated, so it keeps working after the what-if replaces the live region.
  document.addEventListener("click", (e) => {
    const el = e.target instanceof Element ? e.target.closest("[data-panel], [data-tab-link]") : null;
    if (!el) return;
    e.preventDefault();
    show(el.dataset.panel || el.dataset.tabLink);
  });

  if (document.querySelector('[role="tab"]')) {
    document.documentElement.classList.add("js-tabs");
    show(current);
  }

  window.addEventListener("beforeprint", () => {
    document.querySelectorAll(".panel").forEach((p) => { p.hidden = false; });
    document.querySelectorAll("details").forEach((d) => { d.open = true; });
  });
  window.addEventListener("afterprint", () => show(current));

  const form = document.querySelector("form[data-whatif]");
  const live = document.getElementById("live");
  if (!form || !live) return;
  const num = form.elements.namedItem("asking");
  const range = form.elements.namedItem("asking_range");
  const listed = form.elements.namedItem("listed");
  let timer;
  let seq = 0;

  const update = () => {
    clearTimeout(timer);
    timer = setTimeout(async () => {
      const params = new URLSearchParams(new FormData(form));
      params.delete("asking_range");
      if (!params.get("asking")) params.delete("listed"); // listed needs an asking price
      const mine = ++seq;
      try {
        const resp = await fetch("/brief/sections?" + params.toString());
        const html = await resp.text();
        if (mine !== seq) return; // a newer request superseded this one
        live.innerHTML = html; // server-rendered and autoescaped
        show(current);
      } catch {
        live.insertAdjacentHTML("afterbegin", '<p class="banner">The local server stopped. Restart rentsmart-ui.</p>');
      }
    }, 250);
  };

  if (range) range.addEventListener("input", () => { num.value = range.value; update(); });
  num.addEventListener("input", () => { if (range && num.value) range.value = num.value; update(); });
  if (listed) listed.addEventListener("change", update);
  form.addEventListener("submit", (e) => { e.preventDefault(); update(); });
})();
```

```python
"""Local web UI over the same engine. Listens on 127.0.0.1; only POST /brief spends API calls."""

import math
from collections.abc import Awaitable, Callable, Mapping
from dataclasses import dataclass, replace
from datetime import date
from urllib.parse import parse_qs, urlencode, urlsplit

from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse, RedirectResponse, Response
from starlette.concurrency import run_in_threadpool

from rentsmart.contracts import (
    AddressNotFound,
    AmbiguousAddress,
    Brief,
    ConfigError,
    QuotaExceeded,
    RentsmartError,
)
from rentsmart.core.engine import build_brief
from rentsmart.core.facts import OwnerFacts
from rentsmart.core.listing import CurrentListing
from rentsmart.providers.cache import CacheMiss
from rentsmart.providers.rentcast import RentCastProvider
from rentsmart.settings import response_cache, stale_after_days, usage_log
from rentsmart.web import render

DEFAULT_PORT = 8765
MAX_ADDRESS = 200
MAX_RENT = 1_000_000
STATIC = {"app.css": "text/css", "app.js": "text/javascript"}
ERROR_STATUS: dict[type[RentsmartError], int] = {
    AddressNotFound: 404,
    AmbiguousAddress: 409,
    QuotaExceeded: 429,
    ConfigError: 500,
}
NO_CACHE = (
    "The local UI needs the response cache, but RENTSMART_CACHE_DAYS is 0. "
    "Unset it or set it to a number of days."
)


class InputError(ValueError):
    """Form input the CLI would also reject."""


@dataclass(frozen=True)
class BriefRequest:
    address: str
    asking: float | None = None
    listed: date | None = None
    entered: float | None = None

    def query(self) -> dict[str, str]:
        q = {"address": self.address}
        if self.asking is not None:
            q["asking"] = f"{self.asking:g}"
        if self.listed is not None:
            q["listed"] = self.listed.isoformat()
        if self.entered is not None:
            q["entered"] = f"{self.entered:g}"
        return q


def _rent(fields: Mapping[str, str], name: str, label: str) -> float | None:
    raw = fields.get(name, "").strip().replace(",", "").removeprefix("$")
    if not raw:
        return None
    try:
        value = float(raw)
    except ValueError:
        raise InputError(f"{label} must be a number of dollars, got {raw!r}.") from None
    if not math.isfinite(value) or not 1 <= value <= MAX_RENT:
        raise InputError(f"{label} must be between $1 and ${MAX_RENT:,}.")
    return value


def parse_request(fields: Mapping[str, str], today: date) -> BriefRequest:
    address = " ".join(fields.get("address", "").split())
    if not address:
        raise InputError("Enter an address.")
    if len(address) > MAX_ADDRESS:
        raise InputError(f"Address is longer than {MAX_ADDRESS} characters.")
    asking = _rent(fields, "asking", "Asking rent")
    entered = _rent(fields, "entered", "Entered asking rent")
    listed: date | None = None
    if raw := fields.get("listed", "").strip():
        try:
            listed = date.fromisoformat(raw)
        except ValueError:
            raise InputError(f"Listed date must be YYYY-MM-DD, got {raw!r}.") from None
        if asking is None:
            raise InputError("A listed date needs an asking rent.")
        if listed > today:
            raise InputError("Listed date can't be in the future.")
    return BriefRequest(address, asking, listed, entered)


def create_app(port: int = DEFAULT_PORT, today: Callable[[], date] = date.today) -> FastAPI:
    hosts = {f"127.0.0.1:{port}", f"localhost:{port}"}
    app = FastAPI(docs_url=None, redoc_url=None, openapi_url=None)

    def build(req: BriefRequest, *, offline: bool) -> Brief:
        cache = response_cache()
        if cache is None:
            raise ConfigError(NO_CACHE)
        day = today()
        provider = RentCastProvider.from_env(
            cache=cache, today=lambda: day, offline=offline, usage=usage_log()
        )
        listing = (
            CurrentListing(asking_rent=req.asking, listed_date=req.listed)
            if req.asking is not None
            else None
        )
        return build_brief(
            req.address,
            OwnerFacts(),
            provider,
            today=day,
            stale_after_days=stale_after_days(),
            listing=listing,
        )

    def failure(err: RentsmartError, req: BriefRequest) -> HTMLResponse:
        links: list[tuple[str, str]] = []
        if isinstance(err, AmbiguousAddress):
            links = [
                (c, "/brief?" + urlencode(replace(req, address=c).query())) for c in err.candidates
            ]
        return HTMLResponse(
            render.render_error(err, address=req.address, links=links),
            status_code=ERROR_STATUS.get(type(err), 502),
        )

    def bad_input(err: InputError, fields: Mapping[str, str]) -> HTMLResponse:
        page = render.render_index(usage=usage_log().this_month(), error=str(err), values=fields)
        return HTMLResponse(page, status_code=422)

    @app.middleware("http")
    async def local_only(
        request: Request, call_next: Callable[[Request], Awaitable[Response]]
    ) -> Response:
        if request.headers.get("host") not in hosts:
            return Response("Local use only.", status_code=400, media_type="text/plain")
        if request.method == "POST":
            source = request.headers.get("origin") or request.headers.get("referer") or ""
            parts = urlsplit(source)
            if parts.scheme != "http" or parts.netloc not in hosts:
                return Response(
                    "Cross-site request refused.", status_code=403, media_type="text/plain"
                )
        return await call_next(request)

    @app.get("/")
    def index(request: Request) -> HTMLResponse:
        values = dict(request.query_params)
        return HTMLResponse(render.render_index(usage=usage_log().this_month(), values=values))

    @app.get("/brief")
    def brief_page(request: Request) -> HTMLResponse:
        fields = dict(request.query_params)
        try:
            req = parse_request(fields, today())
        except InputError as err:
            return bad_input(err, fields)
        try:
            brief = build(req, offline=True)
        except CacheMiss:
            usage = usage_log().this_month()
            return HTMLResponse(render.render_not_cached(req.query(), usage=usage))
        except RentsmartError as err:
            return failure(err, req)
        entered = req.entered if req.entered is not None else req.asking
        page = render.render_page(
            brief, app=True, entered=entered, listed=req.listed, today=today()
        )
        return HTMLResponse(page)

    @app.post("/brief")
    async def run_brief(request: Request) -> Response:
        body = (await request.body()).decode("utf-8", "replace")
        fields = {k: v[0] for k, v in parse_qs(body).items()}
        try:
            req = parse_request(fields, today())
        except InputError as err:
            return bad_input(err, fields)
        try:
            await run_in_threadpool(build, req, offline=False)
        except RentsmartError as err:
            return failure(err, req)
        return RedirectResponse("/brief?" + urlencode(req.query()), status_code=303)

    @app.get("/brief/sections")
    def sections(request: Request) -> HTMLResponse:
        try:
            req = parse_request(dict(request.query_params), today())
        except InputError as err:
            return HTMLResponse(render.render_notice(str(err)), status_code=422)
        try:
            brief = build(req, offline=True)
        except CacheMiss:
            notice = render.render_notice(
                "Data expired.",
                link="/brief?" + urlencode(replace(req, asking=req.entered).query()),
            )
            return HTMLResponse(notice, status_code=409)
        except RentsmartError as err:
            status = ERROR_STATUS.get(type(err), 502)
            return HTMLResponse(render.render_notice(err.message), status_code=status)
        return HTMLResponse(render.render_live(brief, entered=req.entered))

    @app.get("/static/{name}")
    def static(name: str) -> Response:
        if name not in STATIC:
            return Response(status_code=404)
        return Response(render.static_text(name), media_type=STATIC[name])

    return app
```

Note: the expired link drops back to the entered price (`asking=req.entered`) so "Reload the brief" shows the owner's real price. If `entered` is None, the link has no asking price, which is correct.
